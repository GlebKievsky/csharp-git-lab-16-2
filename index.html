Домашняя работа: одна правильная команда

Двенадцать коротких ситуаций из C#-проекта PayFlow. В каждой нужно выбрать из команд, разобранных на лекции об отмене изменений и архивации, ту единственную, которая подходит именно здесь, и ввести её в терминал.

  • 12 кейсов. Домашняя работа засчитывается, когда все кейсы отмечены галочкой.
  • Ровно одна команда. Решение засчитывается, если репозиторий изменила одна команда. Смотреть status, log и diff можно сколько угодно.
  • Шаг назад. Откатывает репозиторий и терминал на одну команду. В настоящем Git такой кнопки нет.
  • Терминал как Git Bash. Кроме git работают ls, cat, echo, rm, clear, dotnet build и dotnet test. Текстовый редактор не открывается.
